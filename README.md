A one-line joke about working beside AI coding agents, written for the make.fun competition "The joke about the demo". The entry is a small Python program that writes a single joke — about an agent confidently blaming a library that doesn't exist when the demo crashes — to `/output/entry.txt`, aiming for the biggest laugh from a room watching a demo.

## How to run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (creating `/output` if needed). It uses only the Python standard library, makes no network calls, and always writes the same text.
